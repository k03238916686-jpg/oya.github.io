Contacto y correcciones técnicas de OYA

Comunica un error de fórmula, una unidad ambigua o un problema de navegación mediante el repositorio público del sitio.

Comunicar una corrección

Puedes abrir una incidencia en el repositorio público de OYA. Necesitarás una cuenta de GitHub para publicar. Es un canal público, no un formulario privado: no incluyas datos personales, números de cliente ni documentación confidencial.

Para que una observación pueda revisarse, indica:

  1. Dirección de la página y nombre de la herramienta.
  2. Valores introducidos con sus unidades, sin información sensible.
  3. Resultado obtenido y resultado esperado.
  4. Fuente o razonamiento que justifica la corrección.
  5. Navegador y tamaño aproximado de pantalla si el problema es visual.

Qué no se ofrece

Este canal no atiende emergencias eléctricas, reparaciones a distancia ni certificaciones de seguridad. Si una máquina presenta olor a quemado, disparos o comportamiento peligroso, debe evaluarla personal cualificado; un mensaje en una web no sustituye una actuación de seguridad.

El canal de comunicación disponible es el repositorio público. No se garantiza un plazo de respuesta. Si el sistema de incidencias no permite crear una nueva, puedes consultar la actividad del repositorio, pero no compartas información privada en comentarios públicos.

Privacidad al salir de la web

GitHub tiene sus propias condiciones y política de privacidad. La visita al repositorio y cualquier publicación se realizan fuera de OYA. Consulta nuestra política de privacidad para conocer el funcionamiento de este sitio.
