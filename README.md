# OYA · Cuaderno eléctrico

Sitio estático en español para https://oya.to/.

## Contenido

- 7 calculadoras educativas ejecutadas en el navegador.
- 12 guías originales con diagramas SVG propios.
- Páginas de información, metodología, contacto, privacidad y aviso legal.
- Página 404, sitemap XML, robots.txt, metadatos sociales y datos estructurados.

## Publicación

Subir el contenido de esta carpeta a la raíz de la rama `main`. No subir el archivo ZIP sin extraer ni crear una carpeta contenedora. En GitHub Pages, seleccionar publicación desde `main`, carpeta `/ (root)`, y dominio personalizado `oya.to`. Conservar el archivo CNAME.

## Funcionamiento

No requiere servidor de aplicaciones, instalación ni claves. `calculo.js` contiene modelos y control de formularios; `style.css` contiene los estilos. No utiliza bibliotecas, fuentes o imágenes remotas.

Las fórmulas y sus límites están descritos en `metodologia.html`. No se ofrece diseño automático de devanados, selección de protecciones ni certificación de una máquina.

## Contacto

El canal público enlazado es el sistema de incidencias del repositorio. No se ha configurado ningún formulario de envío ni dirección de correo. Si se cambia el canal, actualizar contacto y privacidad de forma consistente.

## Publicidad

Los contenedores `.ad-slot` están ocultos y no se carga código de anuncios. No activar publicidad simplemente quitando `hidden`: primero deben configurarse el servicio, los identificadores propios, la política de privacidad y el consentimiento cuando corresponda. No se incluye un identificador publicitario de otro sitio.

## Comprobaciones de esta versión

102 comprobaciones matemáticas; navegación y formularios en 390 y 1280 px; revisión adicional de desbordamiento en 320 px. Tres páginas representativas sin errores ni advertencias en Schema.org Validator. No se han simulado fechas históricas de publicación.
